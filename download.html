Install

Three clicks, and one blue box to get past.

It's a normal Windows installer. No admin rights needed. The longer walkthrough, including setup and moving your V3 data across, is on the install tutorial.

  1. Download the installerFrom the button above once it's live, or from the Releases page on GitHub.
  2. Run itDouble-click the .exe. It installs for the current user only, so there's no administrator prompt.
  3. If Windows shows a blue "Windows protected your PC" boxClick More info, then Run anyway. See below for why this appears.
  4. Open Parts BinIt's on your Desktop and in the Start menu. First run shows a short tour of what's new, then you're in.
  5. Coming from V3?In V3 go to Settings, Backup to file. In V4 go to Settings, Data and backup, Restore. Everything comes across: items, projects, orders, compartments, settings.
About the "Windows protected your PC" warning. Windows shows this for any app that hasn't been code-signed with a paid certificate, something small free projects usually skip. It does not mean anything is wrong with the app. Click More info, then Run anyway. You only need to do it once. If a downloaded file seems blocked, right-click it, Properties, tick Unblock, OK.
