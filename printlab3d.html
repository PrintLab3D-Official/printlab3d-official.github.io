From one HTML file to a desktop app.

Parts Bin started as a single web page with a desktop shortcut, a quick fix for a drawer full of mystery resistors. Each version added what the bench needed next: orders and projects, then compartments and labels, then backups and themes. V4 turns it into a proper Windows app with a parts-list pipeline that goes straight from your PCB design tool to an order.

It's free and open source because that's how most of the tools on this bench got here.
